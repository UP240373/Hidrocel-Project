HIDROCEL APP - INSTRUCCIONES

📌 CÓMO USAR:
1. Haz doble clic en "start.bat"
2. Espera a que se abra el navegador automáticamente
3. ¡Listo! No cierres la ventana negra mientras uses la app

📌 CÓMO DETENER:
- Cierra la ventana negra (CMD)
- O presiona Ctrl+C en esa ventana

📌 SOLUCIÓN DE PROBLEMAS:
- Si no se abre el navegador, ve a http://localhost:3000 manualmente
- Si ves error de base de datos, revisa tu archivo .env

📌 REQUISITOS:
- Tener MySQL instalado y corriendo
- Puerto 3000 disponible
